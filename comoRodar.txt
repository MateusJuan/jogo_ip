Como configurar o repositório e rodar o jogo
============================================

Requisitos
----------
- Git
- Python 3.13 (o pygame 2.6.1 usado neste projeto tem instalador para essa versão)
  Na instalação do Python no Windows, marque a opção "Add python.exe to PATH".

1. Clonar o repositório
-----------------------
Abra o terminal na pasta onde o time guarda os projetos e rode:

    git clone https://github.com/MateusJuan/jogo_ip.git
    Mude para a pasta do jogo, execute no bash:
    cd jogo_ip

2. Criar o ambiente e instalar as dependências
----------------------------------------------
Dentro da pasta jogo_ip, no PowerShell:

    py -3.13 -m venv .venv
    .\.venv\Scripts\Activate.ps1
    python -m pip install -r requirements.txt

Se o PowerShell bloquear a ativação, rode uma vez:

    Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

e tente ativar de novo.

No Prompt de Comando (cmd), a ativação é:

    .venv\Scripts\activate.bat

3. Rodar o jogo
---------------
Com o ambiente ativado, na pasta jogo_ip:

    python main.py

O personagem nasce no centro do Lobby, o pátio das ruínas.
- Mover: W A S D ou as setas
- Fechar: botão de fechar da janela

O Lobby tem uma escada, ao norte. Ela sobe o castelo nesta ordem:
Lobby → Salão → Galeria → Torre

A Torre é o último andar. Em cada andar, a escada de baixo volta um piso.

As imagens ficam em assets/ e já vêm no clone. Não apague essa pasta.

4. Abrir no Cursor ou no VS Code
--------------------------------
O arquivo .vscode/settings.json aponta o interpretador para:

    .venv\Scripts\python.exe

Abra a pasta jogo_ip no editor. Se o aviso de importação do pygame aparecer, escolha esse interpretador em "Python: Select Interpreter".
